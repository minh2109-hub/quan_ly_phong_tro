Sơ Đồ Tuần Tự (Sequence) - Chức Năng Đăng Nhập & Phân Quyền
BướcNgười Dùng (Client)Trang Xử Lý (login.php)Cơ Sở Dữ Liệu (MySQL)Kết Quả / Chuyển Hướng
1 Nhập username, password và submit form Tiếp nhận POST request, validate dữ liệu đầu vào - Kiểm tra không để trống
2 - Thực hiện Prepared Statement query SELECT * FROM users WHERE username = ? Trả về bản ghi user (nếu có)
3 - Gọi password_verify(password, hash) - Khớp mật khẩu bcrypt
4 (Lỗi) Nhận thông báo lỗi màu đỏ Set thông báo lỗi: "Tên đăng nhập hoặc mật khẩu không đúng" - Giữ nguyên trang login.php
5 (Đúng) - Khởi tạo $_SESSION (user_id, role, ho_ten, tenant_id) UPDATE users SET lan_cuoi_dang_nhap = NOW() Ghi nhận phiên đăng nhập
6 Được chuyển hướng đến trang tương ứng Kiểm tra vai_tro:
• Admin → /admin/dashboard.php
• Khách thuê → /user/dashboard.php		 - Tải giao diện làm việc theo vai trò
